FLUXO DE EXECUÇÃO
═══════════════════════════════════════════════════════════

1. CARREGAMENTO PÁGINA
   ↓
   navegacao.html
   ├─ Carrega CSS (navegacao.css)
   ├─ Carrega Leaflet CDN
   ├─ Cria DIV#mapa
   └─ Carrega navegacao.js
      ↓
      new SistemaNavegacao()
      └─ constructor()
         ├─ Capturar elementos DOM
         ├─ Inicializar mapa (Leaflet)
         ├─ Configurar eventos
         ├─ Obter localização usuário
         │  └─ Navigator.geolocation
         ├─ Carregar instituições
         │  └─ Fetch(/api/get_instituicoes.php)
         │     └─ MariaDB retorna JSON
         ├─ Plotar marcadores
         └─ Atualizar sidebar

2. USUÁRIO INTERAGE
   ├─ Clica em busca
   │  └─ filtrar_instituicoes()
   │
   ├─ Clica em marcador
   │  └─ selecionar_instituicao()
   │     └─ Popup abre
   │
   └─ Clica "Iniciar Rota"
      └─ iniciar_rota(id)
         ├─ calcular_rota_osrm()
         │  └─ Fetch(OSRM API)
         │     └─ Retorna coordenadas
         ├─ desenhar_rota()
         │  └─ L.polyline() no mapa
         └─ mostrar_painel_rota()
            └─ Atualizar HTML painel

      ↓

      ├─ teste_dom()
      │  └─ Verifica elementos DOM

      │  └─ Verifica biblioteca Leaflet
      ├─ teste_geolocation_api()
      │  └─ Verifica API nativa
      ├─ teste_api_instituicoes()
      │  └─ Fetch API GET
      ├─ teste_osrm()
      │  └─ Fetch OSRM
      ├─ teste_sistema_navegacao()
      │  └─ Verifica classe SistemaNavegacao
      └─ mostrar_resumo()
         └─ Taxa de sucesso

DEPENDÊNCIAS E FLUXO
═══════════════════════════════════════════════════════════

navegacao.html
    ├─ Depende de: CSS, JS, CDNs
    └─ Usado por: Navegador

navegacao.css
    ├─ Depende de: Nada (CSS puro)
    └─ Usado por: navegacao.html

navegacao.js
    ├─ Depende de: Leaflet CDN, DOM navegacao.html
    ├─ Faz requisição a: /api/get_instituicoes.php
    ├─ Faz requisição a: OSRM API externa
    ├─ Usa: Geolocation API do navegador
    └─ Usado por: navegacao.html

testes.js
    ├─ Depende de: navegacao.js, DOM
    └─ Usado por: Console (F12)

get_instituicoes.php
    ├─ Depende de: Banco de dados (pin2026)
    ├─ Conecta a: MariaDB/MySQL
    └─ Retorna: JSON para navegacao.js


FLUXO DE DADOS
═══════════════════════════════════════════════════════════

Usuário
  ↓
Navegador
  ↓
navegacao.html
  ├─ Carrega CSS
  ├─ Carrega scripts
  └─ Monta DOM
      ↓
      navegacao.js (inicializa)
      ├─ Cria mapa Leaflet
      ├─ Solicita geolocalização
      │  └─ Navigador responde com coords
      ├─ Fetch /api/get_instituicoes.php
      │  ├─ API consulta BD
      │  ├─ MariaDB retorna instituições
      │  └─ Retorna JSON
      ├─ Plota marcadores no mapa
      └─ Atualiza UI
          ↓
          Usuário vê mapa pronto
          ↓
          Usuário clica em instituição
          ├─ Popup abre
          └─ Usuário clica "Iniciar"
              ├─ navegacao.js chama OSRM
              ├─ OSRM calcula rota
              ├─ Desenha polyline
              └─ Mostra painel de rota

Usuário (Testes)
  ↓
Console (F12)
  ├─ executar_testes()
  ├─ testes.js executa
  ├─ Valida DOM, Leaflet, APIs
  ├─ Faz Fetch para API/OSRM
  └─ Mostra relatório
