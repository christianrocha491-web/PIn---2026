# PIn---2026

Instruções importantíssimas para o bom andamento do projeto:

1) Sempre que mexermos no site, devemos garantir antes que a máquina ( o ambiente da pessoa ) esteja dentro da branch correta;
   
3) Daqui pra frente, o fluxo sempre para o front-end será (nada de novidades, apenas boas práticas):
   
   a) Alguém edita o código;
   b) Sobe no git imediatamente após terminar;
   c) Confere se deu certo o "push";
   d) Avisa o pessoal;

4) Com relação ao banco de dados, apenas as pessoas envolvidas na programação dele deverão fazer inserções ou modificações no mesmo;

5) Todos deverão ter o xampp em suas máquinas para que a visualização completa do projeto seja possível (é um arquivo leve, fiquem tranquilos);

6) Todos deverão ter uma árvore de diretórios no seu localhost ( C:/xampp/htdocs/PIn---2026/ <arquivo_de_interesse> );

7) Haverá um arquivo no projeto que armazenará os scripts do banco para que sejam evitados conflitos e/ou confusões logísticas ( será um arquivo html e o script ficará comentado);

8) O procedimento para modificações no banco será sempre:
   
   a) Abrir XAMPP;
   b) Iniciar Apache e MySQL;
   c) Executar novo update SQL;
   d) Abrir localhost;
